# 远见 · 海外基金筛选

在线地址：[fund.naplesblue.cn](https://fund.naplesblue.cn)。

HTML 基金筛选网页，使用已有 735 个 QDII / 海外指数候选份额与公开数据。Python 3 + curl，无第三方运行依赖。

## 打开

在项目目录执行：

```sh
python3 -m fund_atlas
```

浏览器打开 http://127.0.0.1:8765 。页面右上角“刷新数据”真正请求公开数据源；全量更新需要数分钟，已限制为3个并发请求并添加间隔，遇到上游错误不会绕过限制。服务只监听本机，由 Nginx 提供公网访问。

可从命令行更新：`python3 -m fund_atlas --refresh`。不要与网页刷新同时运行同一个数据目录。直接双击 HTML 时浏览器可能禁止读取 JSON，请使用本地服务。

## 功能

- 投资结构分层：未发现 A 股下的美股方向 / 其他海外方向，以及发现 A 股；另保留待核验。
- 最新披露单位净值及日期、1/3/5 年年化、同窗口最大回撤、每日限额、平台申购费、管理费、IOPV 溢价。
- 详情包括托管费、销售服务费、最高赎回费、投资范围、依据、实际收益区间与来源链接。
- 交易渠道（场内买卖、场外申购、两者均可、待核验）、币种、额度、收益、管理费、溢价筛选；搜索、排序、分页、浏览器本地关注、当前结果 CSV 导出。
- 全量手动刷新先检查缓存、展示共享进度；到期才请求上游，失败清空受影响数据并进入冷却。
- 每个缺失或失败项提供“重新获取”，复用对应来源缓存，过期才重新请求，更新同来源关联项；无有效 IOPV、年限不足等情况会明确标注。

## 重要口径

这是一张研究筛选表，不是已认证的优质基金榜。候选不是独立基金数量，也未全部核验 QDII 资格。

1. 分类为方向初筛。美股 / 海外指数分类根据详情跟踪标的，不能证明没有 A 股；A 股类别依据披露的重仓证券代码，但接口没有报告期，不能当实时持仓。完全排除 A 股必须核验合同和完整定期报告。不得把待核验归入无 A 股。
2. 各份额按自身最新净值截止日算 1/3/5 年年化：`(期末NAV/期初NAV)^(365.25/实际天数)-1`。选择周年日之前最近的净值，允许最多10日间隔。窗口内有分红/拆分标记或净值日变动与源 equityReturn 相差超过0.08个百分点时不算；不把累计净值当作复权净值。数据仍为第三方估算，未与官方复权全量交叉验证。
3. 回撤用同窗口全部有效净值点逐日峰值计算。曲线为近3年抽样展示。净值已反映持续费用，不再次扣管理费。个人申赎及佣金另计。
4. 默认人民币筛选；美元单列。不同截止日、不同策略、不同币种不可视作严格业绩排名。收益缺失为待核验，不是0。
5. 申购状态覆盖原始额度。超大额度、零和缺失不当无限购。实际渠道、身份合并、定投均待核验。平台费率不是全渠道优惠承诺。
6. 场内溢价为价格/IOPV-1。无有效 IOPV 不算，不用滞后单位净值替代。普通非上市份额不适用。保留行情日期，报价有延迟。
7. 刷新先检查服务器共享缓存。净值6小时；历史收益/回撤、费率/结构24小时；申购列表30分钟（单独查申购费24小时）；场内溢价交易时段5分钟。多人同时请求同一个来源只访问上游一次。生产服务另在交易时段定时采集溢价，复用同一来源缓存和锁；其他来源仍由点击触发。
8. 失败会删除该来源的旧值，冷却5/15/30/60分钟后才允许再次请求。缓存与冷却保存在SQLite中，重启或其他用户点击不会绕过。已知休市期间只补取一次行情快照，此后复用并保留行情日期。当前交易日历覆盖2026年，新增年份前需要更新。
9. POST /api/retry，JSON例如 {"code":"008971","field":"nav"}。共享源一次返回的收益/回撤或费率会一起使用。已有任务时返回202并等待共享结果，不报重复请求错误。收藏依然各自保存在浏览器。
10. 运行数据默认在 `work/runtime/`，生产使用 `FUND_DATA_DIR=/var/lib/fund-atlas`。`FUND_ALLOWED_ORIGINS` 设置正式域名。服务监听本机8765端口，由Nginx反代；参考 [部署说明](deploy/README.md)。程序限制同一数据目录只有一个服务进程，运行时请使用网页刷新。

## 开发与验证

要求 macOS 或 Linux、Python 3.10+、curl。运行无第三方 Python 依赖；Node.js 仅用于 JavaScript 语法检查。

```sh
python3 -m unittest discover -s tests -v
python3 -m compileall -q fund_atlas
node --check web/app.js
node tests/test_trade_info.cjs
```

首次启动从 `data/qdii_candidates.csv` 建立候选列表。点击刷新获取数据；首次全量获取可能需要数分钟。`FUND_DATA_DIR` 指定运行目录，`FUND_ALLOWED_ORIGINS` 为逗号分隔的允许来源。收藏存于各自浏览器的 localStorage，切换域名或浏览器不会迁移收藏。

API 探针：`python3 scripts/test_qdii_api.py`；离线分析：`python3 scripts/analyze_qdii_probe.py`。原始响应和输出均写入 `work/`；研究生成的候选清单不会自动替换正式种子。

生产更新、回滚、日志与备份见 [部署说明](deploy/README.md)。数据口径研究见 [API 实测](docs/api-research.md)；[历史交接](docs/archive/handoff-2026-09-11.md) 仅供背景参考，当前行为以本文件及代码为准。

## 交易渠道

渠道按份额代码、名称和上市标记初分，尚非交易所完整上市资格核验。上市 LOF 归入“两者均可”，同时出现在场内和场外筛选中；LOF 的非上市 C 类份额不会因名称含 LOF 被归入场内。暂停申购不改变渠道归类，是否当前开放仍看申购状态和公告。证据不足保留“渠道待核验”。

表格“申购与交易”固定三行：场外申购、场内申购、场内交易。场外金额为来源平台日限额；场内申购未取得独立依据时显示待核验，不能由场外暂停推断；场内交易显示上市情况，不承诺实时未停牌。点击表头按场外日限额数值升降序，人民币与美元分组，暂停、缺失及不适用置后。ETF 一级市场清单尚未接入生产页，历史可行性实测见 [研究记录](docs/primary-subscription-research.md)；不能把该历史样本当作当前额度。详情中说明一级申赎门槛与场外额度的区别。

## 历史单位净值

点击或悬停表格中的基金净值，可看单份额的近 30 天 / 1 / 3 / 5 年历史；切换区间时小窗保持打开，基金详情中也有可切换的大图。30 天从历史序列最新估值日往前按自然日计算。鼠标或触屏移动到图线上方会显示十字虚线、对应的日期与净值刻度，以及来源披露的日涨跌幅。橙点标记来源注明的分红 / 拆分；超过 14 天的缺口不连线。这里是每日一个单位净值的折线，不是开高低收 K 线，也不是复权总回报；分红导致的净值跳变不应直接解释为持有亏损。

逐日序列随已有 `history:<基金代码>` 请求写入服务器共享缓存，不放进首页的批量数据。只读 API：`GET /api/nav-history?code=161128&days=30` 或 `GET /api/nav-history?code=161128&years=3`（years 仅 1/3/5）。打开图表只读缓存，不会重新请求上游；旧缓存可读取代码和截止日一致的本地原始证据，若证据不存在，等待下次历史来源刷新。失败缓存不展示旧值。图表的历史截止日可能比独立的“最新净值”列早，页面分别标注日期。

## 场内溢价历史

悬停溢价数字约 300ms 查看历史；点击固定小窗，手机点击打开，Escape 或关闭按钮收起。支持近 7/30/90 天、零折溢价线、最后采样/最高/最低、样本数和行情时间。缺口超过 20 分钟不连线；仅一个样本时不画趋势，空历史不补零。当前值获取失败时仍可查看过去成功采集的历史。

生产 systemd 设置 `FUND_COLLECT_PREMIUM=1`。服务每 30 秒检查一次时间及缓存，交易时段在 5 分钟缓存到期后批量获取上市候选行情，复用 `quotes` 缓存、失败冷却与刷新锁。工作日 09:30–11:30、13:00–15:00（北京时间，扣除配置假日）自动采集；午休、休市和未知日历年份不自动请求。忙于手动刷新时跳过本次检查，可能留下采样缺口。本地默认不开启，可用同一环境变量开启。

历史存于运行目录 `premium-history.sqlite3`，按基金代码和来源行情时间去重。保存价格、IOPV、溢价、来源时间和获取时间；拒绝无效数值、日期不符、超过20分钟的过期报价和未来报价。不使用滞后基金净值重建溢价；来源没有独立验证的 IOPV 时间戳，记录仍可能存在报价延迟。历史从启用后新获取的有效行情开始累积，没有追溯补齐。

只读 API：`GET /api/premium-history?code=513100&days=30`（days 仅 7/30/90）；查询历史不会触发上游请求。`/api/status` 的 `collector` 显示是否启用、最近尝试/成功/归档时间及错误。历史目前持续保留，界面最多查询90天，数据库随运行目录备份；长期运行应关注磁盘占用。
