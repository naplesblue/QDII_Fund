# QDII 项目交接

交接日期：2026-09-11（北京时间）

## 用户目标与当前授权
用户希望查看中国大陆销售的 QDII 基金的申购限额、场内溢价、投资标的和历史年化收益，以筛选认可的基金，并在这些基金恢复申购或提高限额时及时收到通知。

当前已完成公开 API 初步测试。用户决定将材料转入独立项目继续讨论和开发。本次仅迁移资料；尚未确定建设完整页面，也没有创建监控、自动通知、交易或部署。以下产品方案是讨论建议，不能视作用户已确认的功能清单或投资选择。

## 讨论结论
- 没有确认到公开、官方统一、同时覆盖所有需求且承诺稳定的 API。当前可用方案是第三方公开接口组合，需自建数据口径。
- 集思录适合日常场内查询。其公开会员说明列出的提醒为股票/可转债到价和涨幅提醒，且要求 APP 活动状态；未确认它支持 QDII 恢复申购的后台通知。
- 自建工具最有价值的部分是“已认可基金的自选名单＋额度变化通知”。建议先验证数据与提醒可靠性，再决定是否做完整页面。
- “优质基金”与“当前有额度”应分开：先确定投资标的、风险和费用等筛选条件，再监控购买条件。不能用高历史收益或高溢价直接定义优质。
- 建议比较同类基金的投资区域/行业/指数、3/5年历史年化、同期最大回撤、费用、指数跟踪偏离；场内购买另看流动性与溢价。此框架尚未得到用户逐项确认。
- 场外普通申购按净值确认，场内溢价主要用于渠道比较。ETF、联接基金、A/C及人民币/美元份额不能直接按名称合并。
- 集思录具体上游供应商没有查明，不能声称它从天天基金或东方财富取数。其官方说明确认按交易所披露的 IOPV 计算相关折溢价。

## 已验证的关键数据口径
1. 申购表中基金类型含QDII仅370条，另有365条“指数型-海外股票”。161125、513500、159941等在后者。735条是候选份额集合，不是735只已确认的独立QDII基金；其他海外投资机制可能也需要排除。
2. 候选状态：限大额315、暂停申购133、开放申购195、场内交易86、封闭期4、认购期1、空1。
3. 161125暂停申购，但限额字段仍是10；优先判状态，不能将任何正数当作可购买额度。ETF“场内交易”也不能当作场外开放。
4. 501312限额20，集思录也显示限20；000043限额100。只是快照交叉核对，未验证用户具体渠道可下单额度。
5. 不将超大数值当作确证的无限购；币种、渠道、按身份证/账户合并、跨销售机构累计、定投规则都需公告和渠道校验。
6. 集思录20条样本旧estimate_value及discount_rt全部为空；nav_discount_rt、index_nm、apply_status都有值。净值溢价与IOPV溢价必须分列，净值日期必须保留。游客范围不全，不绕过权限。
7. ETF字段f2价格、f441 IOPV、f402折价率、f297数据日期、f124更新时间。三只样本的(价格/IOPV-1)*100与f402相反，舍入误差均低于0.005个百分点。
8. 513500：2.676/2.4484，对IOPV溢价9.2959%；159941：1.65/1.4881，10.8796%；513100：2.219/1.9873，11.6590%。行情日2026-09-10，不是当前实时报价承诺。
9. 161125最新净值日期2026-09-09。阶段收益变量注释确认syl_1n为近1年11.52%，syl_6y为近6月9.7%，syl_3y为近3个月2.62%，syl_1y为近1个月-1.66%；后两个不是3年和1年。
10. 尚未计算3/5年年化或最大回撤，历史序列需验证分红/拆分及复权口径、币种、共同截止日后再用。不要直接把累计净值当作可靠的分红再投收益序列。

## 复跑方式
在项目根目录：
```sh
python3 outputs/test_qdii_api.py
python3 outputs/analyze_qdii_probe.py
```
仅补测指定接口：
```sh
python3 outputs/test_qdii_api.py etf_selected
```
需要Python 3和curl。无需额外Python库。脚本会覆盖对应原始响应和结果文件；如需保留时间序列，请先存档。离线分析依赖完整首次探针结果；网络失败后不要将既有旧响应当作新数据。脚本是初步诊断工具，没有实现生产级过期防护、重试、变化检测或自动通知。

## 建议的下一阶段
先确认用户实际购买渠道、候选投资方向、通知渠道，以及“达到多少日限额值得提醒”。可先选择10—20个关注份额，做多日数据快照核对，再决定页面和部署。

建议提醒条件：暂停到恢复、限额越过用户门槛、同标的已认可替代基金开放；场内购买可单设溢价门槛。通知需包含代码、渠道、前后变化、数据时间与核验链接；去重、冷却、异常状态和数据过期必须处理。仅在真实有意义变化时通知，不以采集失败推断暂停。

未解决：全市场分类与份额关联；具体渠道额度；限购规则生效时间；行情延迟及IOPV质量；长期稳定性/限流；数据使用授权；年化/回撤计算；部署位置及通知方案。
