## 必须处理的口径
1. 只按类型包含QDII筛选会漏掉161125及多个纳指标普产品。735条只是候选集，应通过基金详情确认，并区分份额币种、A/C和ETF联接关系。
2. 数值限额不能单独决定可申购；源字段未充分表达渠道、币种、跨账户累计、定投等条件。暂停、场内交易、未知状态需单独处理。
3. 不将超大限额数字直接认定为无限购，不将非零数字认定为可购买额度。
4. ETF f402为折价口径：三只样本验证其与自算溢价相反，误差低于0.005个百分点。IOPV的估值质量和更新时间尚未验证；接口域名为push2delay，不承诺实时行情。
5. 集思录nav_discount_rt为相对公布净值的溢价，不能冒充实时估值溢价；游客数据不完整。
6. 品种JS中syl_3y为近三个月，syl_1y为近一个月。3/5年年化应另用经分红、拆分处理且口径验证的历史收益序列计算，本次未计算。
7. 申购接口净值时间只有月日，不代表限购规则生效时间；当前限额还需与基金公告、实际销售渠道核验。

## 文件与复跑
- test_qdii_api.py：读取公开接口，响应存入work/api-probe；可传请求名称只补测指定项目。
- analyze_qdii_probe.py：安全解析保存的JSON/数组，不执行远端JS，生成CSV及摘要。
- api_probe_results.json：逐次URL、HTTP状态、抓取时间、原始文件路径。
- qdii_candidates.csv：735个候选份额的申购表，保留原始字段和字符串。
- etf_sample.json / jisilu_sample.json / data_summary.json：结构化结果。

在项目根目录执行：
```sh
python3 outputs/test_qdii_api.py
python3 outputs/analyze_qdii_probe.py
```
